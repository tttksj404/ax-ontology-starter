Identity findings applied:
- bind user/service subject kind and allowed client_id to server configuration;
- use sub != client_id for user and sub == client_id for service;
- scope kid selection to an exact issuer;
- reject non-allowlisted JOSE headers and duplicate JSON keys;
- restrict pinned public RSA key members, size, and exponent;
- bound NumericDate, token age, and lifetime;
- prevent JWT-shaped failure from falling back to opaque authentication;
- use server-owned person identity to prevent multiple active human Principals.
