# 독립 구현 감사 계약

제공된 소스 스냅샷과 검증 증거만으로 보안·정확성을 독립 검토한다. 외부 도구를 실행하지 않는다. 한국어로 답한다. 설계자의 이전 승인·자체 점수를 재사용하지 않는다.

범위: 합성 자료의 로컬 참조 런타임. 업무 진단, 권한 우선 키워드/그래프 검색, 선택적 검토 초안 모델 어댑터, 사람 승인 후 SQLite 검토 상태 변경. 기업 인증·불변 감사·완전 DLP·물리 반출 통제·실제 업무 시스템 커넥터는 별도 도입 조건이다.

확인할 것: 테넌트/그룹/등급/목적, 숨은 객체와 없는 객체의 동일 처리, 그래프 탐색 경계, 자료 신선도, 승인 해시·독립 승인, 현재 권한 회수, 멱등·동시 수정·원자성·복구, 모델 출력의 실행권 배제, 전송 경계, 팩 계약. 재현 가능한 결함을 파일/줄/입력/결과/최소 수정/회귀 검증으로 설명한다.

출력: VERDICT: PASS / NEEDS_FIX / FAIL, 필수 수정, 남은 운영 조건, 선택 개선, 제공 스냅샷과 선언 범위에 한정되는지. 마지막에 IMPLEMENTATION_AUDIT_COMPLETE를 출력한다. 모델은 테스트를 직접 실행하지 않았으므로 제공된 실행 증거와 정적 검토를 구분한다.
